# libs/

Building needs **Xaero's World Map 1.45.0 for Fabric 1.21.11**, remapped to **Yarn 1.21.11+build.3** names, saved here as
`xaeroworldmap-fabric-1.21.11-1.45.0.jar`. It's compile-only: nothing from Xaero ends up in the Basemaps jar.

Xaero's mods aren't ours to redistribute, so the jar is not in this repo. Remap the official jar (from Modrinth/CurseForge)
from intermediary to Yarn named with tiny-remapper and the Yarn 1.21.11+build.3 mappings, then drop it in this folder.
