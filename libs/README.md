# libs/

Building needs **Xaero's World Map 1.46.1 for Fabric 26.2**, saved as
`libs/xaero-26.2/xaeroworldmap-fabric-26.2-1.46.1.jar`. It's compile-only: nothing from Xaero ends up in the Base Map jar.

Minecraft 26.x isn't obfuscated, so Xaero's jar already uses the same (Mojang) names as this build. Use the official
jar from Modrinth/CurseForge as-is, no remapping.

Xaero's mods aren't ours to redistribute, so the jar is not in this repo.
